# agent-python-strands

Reference implementation of the Python (Strands Agents) track. `main.py` is at the latest ported module (`memory`); the workshop pages show each step from `create` onwards.

```bash
mkdir -p static && cp ../ui/* static/
export AGENTCORE_MEMORY_ID=<memory id>
uv run main.py          # http://localhost:8080
```
